## “防 DDoS”这三个字，各家标的不是一回事

挑抗 DDoS 的 VPS，最容易踩的坑是把三个完全不同的数字当成同一件事比：**端口带宽、清洗容量、黑洞阈值**。

端口带宽是你这台机器网卡能跑多快。SixtyNet LAX-STARTER 配置里的“2G Premium Network”、LAX-LARGE 的“10G Premium Network”就是这一类，说的是 2 Gbps 和 10 Gbps 的端口速率，和能不能扛住攻击没有直接关系。Infrawire 在页面上写“最高 10 Gbit/s 端口”，同一句话里也把 DDoS 过滤单独列成一条，两个概念是分开的。vShield 写“1 Gbps”，指的是网络规格，防护能力它是另外用“过滤在网络层、到达 VPS 之前完成”来描述的。

清洗容量是上游清洗中心能吸收多少攻击流量。OVHcloud 在自家防护 VPS 页面上用的是“unmetered / unlimited”，强调不限量、不额外收费，但没给具体数字。这个口径对读者最友好，也最难验证。

黑洞阈值是攻击超过清洗能力之后会发生什么。多数机房的默认动作是 blackholing：把这个 IP 的入站流量整体丢弃，攻击停了，你的网站也一起停了。免费防护最容易被忽略的代价就在这里——防护不是失效，是连正常访问一起掐掉。

SixtyNet 官网对 LAX 系列只标了 DDOS Protection，没有公布清洗容量数字。GitHub 上有两篇第三方测评称 LAX 系列的处理能力在 1000 Gbps 以上，这个数字官网页面查不到，只能当参考，不能当承诺。真正要确认的是两件事：攻击流量会不会计入你那 5TB 或 40TB 的流量额度，以及清洗被打穿之后是限速还是直接黑洞。这两条建议下单前问客服，答案比参数表更能决定你被打那天是掉线十分钟还是掉线一天。

## 三类攻击、清洗和黑洞：被打时你的站会经历什么

DDoS 的本质是用大量被感染的设备同时向目标发请求，把带宽、连接数或 CPU 占满，让真实用户进不来。按打法分三类，防护手段也不同。

流量型攻击靠蛮力，比如 UDP flood 往随机端口灌包、ICMP flood 用 ping 请求把服务器拖垮。这类攻击峰值高、特征明显，靠流量过滤、速率限制和异常峰值检测来挡。

协议型攻击更阴，SYN flood 发大量连接请求却从不完成握手，服务器一直等着，内存被耗光；Slowloris 开一堆连接但极慢地发数据，把连接池长期占住，对 Apache 和 Nginx 尤其有效。这类攻击不一定产生巨大流量峰值，反而更难发现，通常用防火墙规则、连接超时来缓解。

应用层攻击打的是业务逻辑，HTTP flood 用海量请求压垮 Web 服务，DNS query flood 让域名解析不出来。因为流量不一定大，得靠 WAF、IDS 和速率限制。

所谓清洗，就是在这些流量到达你的 VPS 之前，在上游网络做分析、过滤和丢弃，只把正常请求放过去。vShield 对这个过程的描述是“在网络层、到达服务器之前实时完成”，好处是不占用你机器本身的资源。

没有任何方案能保证 100% 清洗。OVHcloud 在自家防护 VPS 页面上也写明，防护效果取决于攻击规模、复杂程度、清洗系统的容量，以及被攻击应用自身的漏洞。这句话的意思是：防护能显著降低风险和影响，但挨打时服务降级、部分地区访问变慢，都是可能发生的事。买之前按这个预期做计划，比相信“无限防护”的字面意思靠谱。

## 哪些人不需要买带高防的 VPS

三种情况可以先不追高防。

第一种，源站 IP 没暴露、已经在用 CDN 前置的站。攻击流量会先打到 CDN 边缘被吸收，源站只接受回源请求。这种情况下，一台普通 VPS 加 CDN 的组合，比多花钱买高防档更划算，前提是源站 IP 真的没在 DNS 记录、邮件头或历史解析里泄露过。

第二种，日均流量很小、从没被盯上的个人博客和文档站。被打是小概率事件，多付的防护溢价可以省下来买备份。

第三种，主要担心的是 CC 攻击（大量请求打接口或登录页），而不是流量型攻击。这类问题更依赖 WAF 规则、验证码和速率限制，网络层清洗帮不上太多。

反过来说，游戏服、语音服、公开 API、外贸独立站这几类，IP 天生暴露、被打成本低、掉线直接损失收入，防护值得一开始就带上。SixtyNet 的 LAX-STARTER 对这类场景是够用的起点：2 核 2G 撑十几个人的 Minecraft 或语音服没问题，5TB 流量对文字类站点和 API 也算宽裕。

## 常见问题

**抗 DDoS VPS 和普通 VPS 差在哪？**
差在网络层的清洗能力。vShield 的说法是，市场上很多主机商把防护作为选项出售，或者只给部分套餐配；普通 VPS 被大流量打过来时，机房的标准动作往往是黑洞，IP 一封，服务就没了。

**防护开着会不会拖慢我的服务器？**
过滤在上游网络完成，不消耗你 VPS 的 CPU 和内存。vShield 明确写“过滤发生在上游，正常流量照常到达”。真正影响速度的是机房位置和线路，不是防护开关。

**被打的时候会不会直接封我 IP？**
取决于攻击是否超过清洗容量。超过之后很多机房会 blackholing，把整个 IP 的流量丢弃，攻击停了你的网站也停了。这是买之前必须问清楚的一条：超限之后是限速、清洗扩容，还是直接黑洞。

**还需要另外装防火墙吗？**
需要，但它解决的是另一类问题。防火墙和入侵检测管的是未授权访问、端口暴露、暴力破解；DDoS 防护管的是流量压垮可用性。两者不互相替代，系统补丁、备份、SSH 密钥登录这些基础动作也一样不能省。

**流量额度被攻击打爆了要加钱吗？**
官网没有说明攻击流量是否计入套餐额度。LAX-STARTER 是 5TB、LAX-LARGE 是 40TB，如果你的业务本身流量接近上限，这一条务必提前确认。
